# PR 결과·검토 보고서 템플릿 (관공서 서체 · 흑백)

PR을 하나씩 검토·보고하는 인쇄용 한국어 PDF를 만드는 틀입니다. 흑백 프린터 출력을 기준으로 합니다.

## 파일

| 파일 | 역할 |
|---|---|
| `report.css` | 서식 전체 (A4, 서체, 크기, 줄 간격, 흑백 회색). `@@HEADER@@`는 머리말로 바뀝니다. |
| `make_report.py` | 조립 함수(`document`, `summary`, `chg`, `section`, `sub`, `ul`, `table`, `note`, `verdict`, `figure`), `render`(headless Chrome으로 PDF 출력), `verify`(검사). CLI: `python3 make_report.py 내용.py 출력.pdf` |
| `example_content.py` | 가장 작은 예시 보고서 (2쪽) |

## 파일 이름과 제목

- 파일: `보고-{짧은 한국어 제목}_결과보고서.pdf` (merge 끝난 PR) 또는 `보고-{짧은 한국어 제목}_검토보고서.pdf` (merge 전 검토).
  예: `보고-짧은제목_검토보고서.pdf`. `보고-`는 문서번호 접두어입니다. 번호(예: `보고-2026-0042`)는 렌더할 때 머리의 문서번호 줄에 찍고, 파일 이름에는 넣지 않습니다.
- 문서 종류 줄: `결 과 보 고 서` / `검 토 보 고 서` (글자 사이 띄움). 제목은 이중 테두리 상자 안, 가운데 정렬.
- 머리말(오른쪽 위): 호출하는 쪽이 넘기는 짧은 문구. 예: `PR #n 검토 보고`. 쪽 번호(아래 가운데): `- n / N -`.

## 구성 (순서 고정)

1. **머리**: 문서 종류, 제목 상자, (문서번호)·기안일·기안·대상(PR 링크) 표, 오른쪽에 **결재** 상자 (기안 / 결재, 결재 칸 아래 작은 글씨로 `merge 대기` 또는 `10/31 merge`. `10/31 merge`는 지금 찍히는 값이고, 전결이 없을 때의 문장은 `{월}/{일} 완료`입니다. ▲ 값은 그대로). 전결이 있고 마지막 칸의 사람이 머지했으면 `approver_note`에 `머지: 정다은(전결)`처럼 전결한 사람의 이름을 적습니다. 날짜는 적지 않습니다. 머지한 사람의 이름이 아닙니다). 데이터 파일로 그리는 결과보고서는 `skills/approval-line`의 결재란을 받아 `head(sign=…)`로 끼웁니다.
2. **요약** 상자: 검은 띠 제목 `요 약`, ○ 3–4줄. 각 줄은 개조식(…함, …음, …됨)으로 끝냅니다.
3. **상태 변화** 표: `전에는` 행 (회색 칸, 회색 글씨) / `이제는` 행 (검은 칸에 흰 글씨, 내용은 조금 굵게).
4. 큰제목 6개: `□ 1. 개요`, `□ 2. 배경`, `□ 3. 변경 내용`, `□ 4. 검증 결과`, `□ 5. 위험 요소`, `□ 6. 판정`. 소제목은 `4.1 …`.
5. **판정** 상자: 판정 기호 + 문구, 옆에 `머지하러 가기 →` 링크 단추(PR URL), ○ 근거, 판정 구분 범례, `권장 머지 순서`.
6. **붙임**: 차트마다 한 쪽 (`붙임 1. …`). 짧은 차트는 `figure(..., flow=True)`로 본문 뒤에 이어 붙일 수 있습니다.

## 계층 기호

| 기호 | 쓰임 | 서체 |
|---|---|---|
| □ | 큰제목 (h2) | Noto Sans CJK KR Bold 15.5pt, 위 여백 25pt |
| ○ | 본문 1단계 (`ul > li`) | Noto Serif CJK KR Regular 13pt, 위 여백 5pt |
| - | 본문 2단계 (`ul ul > li`) | 같음 |
| ※ | 참고 (`note()`, `p.note`) | Noto Sans CJK KR Medium 12pt |

## 판정 기호 (색 없이 기호와 굵기로 구분)

`verdict(kind, url, items, order)`, `kind`는 다음 중 하나:

| kind | 표시 | 단추 |
|---|---|---|
| `ok` | ✔ 머지 가능 | 있음 |
| `warn` | ▲ 확인 필요 | 있음 |
| `hold` | ✖ 보류 | 있음 |
| `done` | ✔ 머지 완료 | 없음 (원문 링크를 본문에) |

기호는 검은 테두리 작은 상자 안에 Black 굵기로 넣습니다. 범례 `판정 구분: ✔머지 가능 · ▲확인 필요 · ✖보류`는 늘 같습니다.

## 서체 (3가족 이내 · 서체는 SIL OFL 1.1)

| 요소 | 서체 · 크기 · 줄 간격 |
|---|---|
| 문서 제목 | Noto Sans CJK KR Black 21pt |
| □ 큰제목 | Noto Sans CJK KR Bold 15.5pt |
| ○ / - 본문 | Noto Serif CJK KR Regular 13pt, 160% |
| 요약, 결재, 머리말, ※ | Noto Sans CJK KR Medium 12pt (머리말 10pt) |
| 표 | Noto Sans CJK KR Regular 10.5pt, 130% |
| 쪽 번호, 차트 설명 | Noto Sans CJK KR 10–12pt |
| 코드 이름 | Noto Sans CJK KR Medium (고정폭 서체를 따로 쓰지 않음) |
| ✔ ✖ (▲ 포함 판정 기호) | Gothic A1. Noto CJK에 ✔ ✖ 글리프가 없어 이 기호에만 씁니다 |

※ 서체 파일은 이 저장소에 들어 있지 않으며 이름으로만 지정합니다. 각 서체는 배포처(Noto CJK: github.com/notofonts/noto-cjk, Gothic A1: Google Fonts)에서 직접 설치하며, 서체에는 SIL Open Font License 1.1이, 이 저장소의 파일에는 저장소 LICENSE(MIT)가 적용됩니다.

Noto CJK KR의 Medium·Black 굵기와 Gothic A1을 설치한 뒤 씁니다. 서체 가족 이름이 그대로 잡혀야 합니다.

여백: A4, 위·아래 15mm, 좌·우 20mm.

## 흑백 규칙

- 색은 검정(`#000`)과 흰색, 그리고 검정의 투명도(`rgba(0,0,0,a)`)만 씁니다. 다른 색은 쓰지 않습니다.
- 표: 0.5pt 검은 선, 위쪽 1.4pt 굵은 선, 머리 행은 검정 8%를 깝니다. 상자는 6–8%를 깝니다.
- 링크는 검은 글씨에 밑줄. 강조 숫자는 굵게 하고 밑줄을 긋습니다 (`<span class="red">`, 이름은 예전 그대로).

## 검사 (`verify(pdf, png_dir)`)

다음 값을 돌려줍니다:

- 쪽 수와 크기.
- 들어간 서체와 허용 밖 서체(`disallowed_fonts`). 이 목록이 비어 있어야 대체 서체나 두부(□) 글자가 없습니다.
- 쪽마다 최대 채도(`max_chroma`). 0이어야 합니다.
- 쪽마다 채움 비율(`page_fill`). 마지막 쪽이 아닌데 0.5 아래이면 내용을 옮기거나 줄이세요.
- 링크 URL 목록.
- 쪽별 PNG와 흑백 PNG.

PNG는 직접 열어 확인하세요.

## 문장 규칙

- 업계 용어(lease, merge, CI, TLC, compare-and-set 등)만 영어로 쓰고, 나머지는 한국어로 씁니다.
- 본문은 개조식으로 끝냅니다(…함/…음/…됨). 시각은 KST로 적습니다.
